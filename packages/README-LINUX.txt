Mossy Woss OS — Linux install (Debian/Ubuntu/Fedora/Arch/anything)
==================================================================

Quick install:
    chmod +x install.sh
    ./install.sh

Then launch with the command:  mossywoss
Or find "Mossy Woss OS" in your app menu (GNOME/KDE/Cinnamon/XFCE etc).

What the installer does (user-level only, no root):
- copies mossywoss_os.html to ~/.local/share/mossywoss-os/
- adds the `mossywoss` command to ~/.local/bin
- adds a menu entry with icon

Uninstall:  ./uninstall.sh

Manual alternative: just open mossywoss_os.html in any modern browser.

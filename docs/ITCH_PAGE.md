# MWO - MossyWoss OS - itch.io page copy

## Short description (subtitle field)
A whole operating system that lives in one HTML file. 87 apps, games, a code studio, an animation studio and a store - no install, no account, runs in your browser.

## Main description (itch page)
MWO - MossyWoss OS is a complete desktop-style operating system that boots straight in your browser from a single HTML file. No install, no account, no internet needed after loading - everything runs and saves locally on your own device.

**What is inside**

- 87 working apps and games, all original: life sims, survival games, arcade, puzzles, a 3D voxel world and more
- Code Studio: a real code editor with a built-in C / C++ / C# interpreter plus HTML, CSS, JS and JSON, so you can write and run programs right in the OS
- Visual Code: tap-together blocks and blueprint nodes for no-code game logic, with live sound effects and visual effects blocks
- Animation Studio: 2D and 3D keyframe animation, image-frame import, onion skinning, video and PNG export
- Game Builder Kit: build your own game or app, zip it up, and publish it to the in-OS MWO Store
- A full file system with drag-and-drop, real zip extraction, an executable (PE) inspector that honestly reads .exe headers, and a browser with live web search
- OS Lab: a catalog of open-source operating system projects you can launch and explore - always linked with credit, never bundled
- Themes, wallpapers, a recorder, media tools and a desktop that feels familiar without copying anyone else's look

**Honest notes**

- MWO is a web-based OS simulation, not a replacement for your real computer. PC programs (.exe) cannot be executed in a browser - the included inspector reads their real header data instead of pretending.
- Everything here is original work, MIT licensed. No third-party assets are bundled; projects deep-linked from OS Lab stay attributed to their owners.
- Your data stays with you: storage is local to your browser. Clearing browser data clears the OS.

Works on desktop and mobile browsers. Best experienced full-screen.
